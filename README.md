# Expense Tracker - Личный финансовый трекер

**Автор:** Мирослава Петрова (пример)

## Описание программы

Expense Tracker — это десктопное приложение для отслеживания личных расходов с графическим интерфейсом. Позволяет добавлять расходы, фильтровать их по категориям и датам, а также автоматически подсчитывать сумму за выбранный период. Данные сохраняются в JSON-файл.

## Возможности

- ✅ Добавление расходов с указанием суммы, категории и даты
- ✅ Валидация ввода (положительная сумма, корректный формат даты)
- ✅ Фильтрация по категории и диапазону дат
- ✅ Автоматический подсчёт общей суммы за отфильтрованный период
- ✅ Удаление записей
- ✅ Сохранение и загрузка данных в/из JSON
- ✅ Удобный табличный интерфейс
